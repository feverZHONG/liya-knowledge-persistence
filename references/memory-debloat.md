### C20g · 要把条目写到「最前面」：工具只会追加，排序得自己重排文件

- memory 工具的 `add` 实现是 `entries + [content]`（**永远追加到末尾**），没有插入位置的参数——被要求「写到最前面」时：**内容改动仍走工具批量 operations，最后一步才重排文件**，别整份手写。
- 重排前先对齐 round-trip 门槛（源码 `tools/memory_tool_store.py` 的 `_detect_external_drift`）：文件必须满足 `raw.strip() == "\n§\n".join(strip非空段)` **且单条不超过字符上限**，否则下次工具调用会被判「外部漂移」直接拒写。做法：按 `\n§\n` 切分 → 各段 `strip()` 去空 → 目标条提到 index 0 → 同目录临时文件 + `os.replace` 写回。
- 自证：写完拿**同文内容**调一次 `replace`——它走带 drift 检查的 `_mutate`（`add` 是 `skip_drift=True`，验不出来）；返回 success、usage 不变 ＝ 文件能被工具原样读写、顺序也保住了。
