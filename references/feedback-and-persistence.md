### B14 · 反馈落实（用户纠正→落文件 + 落 memory）

14. **反馈落实（用户纠正→落文件 + 落 memory）** — 用户纠正格式/语调/做法/流程，**直接写进对应 md 文件，不只存 memory**（只存 memory = 只说不做）。流程：① 识别领域（台风→typhoon skill、日常回复→AGENTS.md、语音→voice-output）② 写进对应文件 ③ memory 替换特别流程：先读 memory 确认旧规则原文、登记到对应文件后再替换——不确认原文就写 old_text = 乱来


### B14b · 反向也成立：行为类口径必须同时落 memory

- ⚠️ **反向也成立：行为类口径必须同时落 memory** — 文件/skill 是**按需加载**的，而且**会话之间互不相通**（私聊里纠正过的话，群会话上下文里没有）。只把口径补进 skill，别的会话照样按旧习惯说话——**纠正当场看着生效，下一个会话照旧犯**。只有 **memory 每轮注入、每个会话都在**（含群会话），是唯一能穿透到本会话之外的通道。


### B14c · 判据：这条口径要在本会话之外生效吗？

- **判据：这条口径要在本会话之外生效吗？** 要 → 当场写进 memory（skill 管细则，memory 管穿透；memory 满就按第 20 条减法腾地方）。当天在别的会话里又被犯一次 = 这条没做到，回去补 memory 而不是再补一遍 skill。
