# 健康/饮食类事实核查

> 触发：饮食观察、生理现象、健康常识类问题（例：「柠檬茶是不是让人尿频」）。
> 注：原计划挂 info-hunt 下，该 skill 手动创建被自动策展锁定，故落在此处。若 info-hunt 后续可写，可考虑合并过去。

## 流程

1. **中文平台找共识** — mmx search 中文关键词。博禾医生 / 39健康网 / 妙手医生 / 有来医生 / 大众养生网，数量多但互相抄，单条只能当线索。
2. **英文权威交叉背书** — Mayo Clinic / Healthline / NIH 机构页面。明确把诱因列出来的才算实锤（Mayo Clinic 的 frequent urination causes 页把 caffeine 与饮酒、过量饮水并列）。
3. **结论给机制 + 判断 + 注意事项** — 分层说清机制、说明是否正常生理反应、给一句实操提醒（如「别当水喝，晚间少喝」）。

## 踩坑

- **英文搜「caffeine」会被 Java 缓存框架 Caffeine 污染**（2026-08-01 实测）。`mmx search "caffeine diuretic"` 返回的全是缓存库教程，一条医学结果都没有。解法：加限定词（healthline / mayo / medical / frequent urination）或直接用完整问句。
- 中文健康平台权威性排序：三甲医生署名回答（如大众养生网「黄海鹏-主任医师」）> 平台小编文。引用时标注署名，不把小编文当权威。

## 归档

结论写入 `<记忆目录>/health-notes.md`（生活健康笔记，含机制 + 来源清单）+ 当日日记（日记类 skill（作者环境，未单独公开） 规范，自己视角消化版）。

## 实例：柠檬茶尿频（2026-08-01）

机制四层：① 茶底咖啡因（主力，扩肾血管→肾血流量↑，Mayo Clinic 背书）② 柠檬酸/苹果酸/维C（促进肾脏代谢、维C 刺激膀胱）③ 液体量本身 ④ 含糖渗透性利尿。结论：正常生理反应，非疾病。
